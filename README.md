# Handwriting AI Teacher Dashboard

A teacher-facing dashboard for handwriting screening and student support insights.

## What this project does

- Provides a centralized teacher portal for monitoring handwriting screening activity.
- Displays an at-a-glance dashboard with AI-style signals such as total students, uploaded samples, flagged students, and generated reports.
- Shows recent activity, upcoming events, and classroom risk summaries.
- Lets teachers search and filter student screening records by name, ID, class, risk level, date, teacher, age, and gender.
- Enables quick student review through a detail modal with risk insights, previous reports, attendance summary, and teacher notes.
- Supports handwriting sample upload using drag-and-drop or file selection.
- Visualizes an uploaded sample preview and simulates analysis progress, processing steps, and success confirmation.
- Provides a handwriting sketch canvas with live spacing, consistency, and effort metrics.
- Includes interactive analytics charts for class screening counts, risk distribution, monthly trends, radar patterns, and progress scatter.
- Offers light/dark theme switching and accessibility controls for high contrast and larger font sizes.

## Key user experiences

- Teacher dashboard with curated support signals and risk heatmap.
- Searchable, sortable student screening table.
- Handwriting sample upload workflow with sample preview and analysis feedback.
- Interactive student details modal for quick follow-up planning.
- Live handwriting tracing and sample mode for classroom observation.
- Visual risk reporting via charts and progress indicators.

## Notes

- This is a static prototype focused on the teacher-facing experience.
- Data and analysis are simulated for demonstration purposes.
- No backend integration is included in this version.
